# Getting started with Legacy Promo V1

Welcome to `legacy-promo-v1`. This guide gets you from zero to a running local copy.

## Prerequisites

- Docker
- Access to the adaptive-labs GitHub org

## Run locally

```bash
git clone git@github.com:adaptive-labs/legacy-promo-v1.git
cd legacy-promo-v1 && make dev
```

## First task

Pick a `good-first-issue` and ship a small change end to end.
